## 재생 안내 개선

- 재생 불가 안내를 기존 플레이어와 어울리는 작은 회색 카드로 정리했습니다.
- 장식 아이콘, 브랜드명, 브라우저 배지와 중복 설명을 제거했습니다.
- ‘웹 플레이어 열기’ 링크를 없애고 ‘주소 복사’만 남겼습니다.
- Chrome, Firefox 등 WebGPU 지원 브라우저에서 열도록 안내합니다.
- 파일 미리보기, 그래픽 초기화 실패, 네트워크 오류에 필요한 설명을 구분했습니다.

## 개발 문서

- MAP.md와 DEVELOPMENT.md에 프로젝트 구조 및 공통 개발 규칙을 정리했습니다.
- 아이콘 스타일과 명시적인 요청에 따른 배포 원칙을 기록했습니다.

## 검증

- 시작 흐름·주소 복사 테스트 10개 통과
- 배포 파일 구성 및 JavaScript 구문·모듈 경로 검증 통과
- PC·모바일 안내 카드 화면 확인
